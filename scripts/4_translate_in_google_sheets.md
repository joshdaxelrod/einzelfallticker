# Step 4: Translate in Google Sheets

There's no script for this step. I did the translation by hand in Google
Sheets, using its built-in `GOOGLETRANSLATE` formula.

The instructions are in
[Run it yourself → Step 4](../docs/run-it-yourself.md#step-4-translate-in-google-sheets).

When you're done, save the translated sheet as `output/4_releases_english.csv`
and run step 5.
